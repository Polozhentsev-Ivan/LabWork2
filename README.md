[![Build Status](https://img.shields.io/badge/build-passing-brightgreen)](https://github.com/Polozhentsev-Ivan/LabWork2/actions) 


## 🎮 Обзор

**CARD WORLD** — это увлекательная RPG игра, построенная на уникальной концепции, где все существа, объекты и предметы представлены в виде карт! Погрузитесь в мир, полный приключений, квестов и сражений, где каждая карта имеет значение.

## ✨ Особенности

*   **Уникальная механика карт**: Весь игровой мир и его элементы — это карты.
*   **Система квестов**: Выполняйте разнообразные задания, от охоты на монстров до сбора редких предметов.
*   **Развитие персонажа**: Улучшайте своего героя, получайте опыт и новые способности.
*   **Процедурно генерируемая карта**: Исследуйте постоянно меняющийся мир.
*   **Текстовый интерфейс**: Классический игровой опыт в терминале.

## 🚀 Начало работы

### Предварительные требования

*   Компилятор C++ (поддерживающий C++17 или выше)
*   `make`
*   `Doxygen` (для генерации документации)

### Сборка проекта

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Polozhentsev-Ivan/LabWork2.git
    cd LabWork2
    ```
2.  Для сборки основного приложения:
    ```bash
    make
    ```

### Запуск игры

После успешной сборки запустите игру:

```bash
./card_world [путь_к_файлу_карты.txt] 
```
Если путь к файлу карты не указан, будет использована карта по умолчанию (`map_test.txt`).

## ⚙️ Тестирование

Проект использует Google Test для модульного тестирования.

1.  Для сборки тестов:
    ```bash
    make test
    ```
2.  Для запуска тестов:
    ```bash
    ./cw_test
    ```

## 📚 Документация

Проект использует Doxygen для генерации документации.

1.  Для генерации документации:
    ```bash
    make docs
    ```
    Сгенерированная документация будет находиться в директории `documentation/html`.

2.  Для очистки сгенерированной документации:
    ```bash
    make cleandocs
    ```

## 🛠️ Скрипты Makefile

*   `make all` или `make`: Собирает основное приложение.
*   `make test`: Собирает тесты.
*   `make clean`: Удаляет объектные файлы и исполняемый файл основного приложения.
*   `make cleanall`: Удаляет все сгенерированные файлы, включая тесты и документацию.
*   `make docs`: Генерирует документацию с помощью Doxygen.
*   `make cleandocs`: Удаляет сгенерированную документацию.
